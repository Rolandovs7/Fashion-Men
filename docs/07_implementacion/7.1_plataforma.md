## 9. Justificación de Elecciones

### ¿Por qué FastAPI?
- Alto rendimiento (async)
- Documentación automática (Swagger)
- Type hints de Python
- Fácil integración con IA

### ¿Por qué Angular?
- Framework robusto de Google
- TypeScript tipado
- Arquitectura modular
- Ideal para paneles admin

### ¿Por qué Flutter?
- Multiplataforma (Android + iOS)
- Alto rendimiento (motor propio)
- SDK de cámara integrado
- Ideal para RA

### ¿Por qué PostgreSQL?
- Open source
- ACID compliance
- Soporte JSON
- Escalable
