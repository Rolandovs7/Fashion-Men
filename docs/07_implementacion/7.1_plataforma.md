## 9. Justificación de Elecciones

### ¿Por qué FastAPI?
- Alto rendimiento (async)
- Documentación automática (Swagger)
- Type hints de Python
- Fácil integración con IA

### ¿Por qué Angular?
- Framework robusto de Google
- TypeScript tipado
- Arquitectura modular
- Ideal para paneles admin

### ¿Por qué Flutter?
- Multiplataforma (Android + iOS)
- Alto rendimiento (motor propio)
- SDK de cámara integrado
- Ideal para RA

### ¿Por qué PostgreSQL?
- Open source
- ACID compliance
- Soporte JSON
- Escalable

## 10. Sistema de Diseño "Quiet Editorial Luxury"

A partir de Septiembre 2026, todo el frontend web utiliza un sistema de
diseño consistente llamado **"Quiet Editorial Luxury"**:

### Tokens de diseño (Tailwind 4 @theme)
- Paleta: ms-black (#0a0a0a), ms-amber (#d97706), ms-cream (#fef3c7),
  ms-alabaster (#fafaf9), ms-stone (#f5f5f4), ms-ink (#171717),
  ms-slate (#525252).
- Tipografías: Playfair Display (display), Plus Jakarta Sans (sans).
- Sombras: shadow-card, shadow-modal-soft.
- Radius: 12-16px (rounded-xl, rounded-2xl).

### Componentes reutilizables (shared/ui)
12 componentes base + barrel (index.ts) en `frontend/src/app/shared/ui/`:
app-button, app-input, app-select, app-modal, app-alert, app-toast,
app-loader, app-skeleton, app-empty-state, app-badge, app-price,
app-footer.

### Páginas rediseñadas
- **Cliente:** Home, Catálogo, Producto, Carrito, Checkout, Pedidos,
  Login, Registro, Forgot, Reset, Reservas, Notificaciones.
- **Admin:** Panel completo con 12 secciones de catálogo + operaciones
  + reportes + configuración + punto de venta + inventario + usuarios
  + permisos.
