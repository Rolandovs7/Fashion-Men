# 8.1 - Plan de Pruebas

## 1. Objetivos

1. Validar el funcionamiento correcto de los casos de uso implementados
2. Verificar la integración entre frontend, backend y base de datos
3. Comprobar las reglas de autenticación, autorización y roles
4. Validar la integridad de la información
5. Detectar errores antes del despliegue

## 2. Estrategias de Prueba

| Tipo | Descripción | Enfoque |
|------|-------------|---------|
| **Unidad** | Verificar funciones individuales | Caja blanca - pytest |
| **Integración** | Comunicación entre capas | Web → API → BD |
| **Validación** | Cumplimiento de RF | Caja negra |
| **Rendimiento** | Tiempos de respuesta | Autenticación, listados |
| **Aceptación** | Satisfacción de actores | Escenarios reales |

## 3. Alcance

### Backend (FastAPI)
- Todos los endpoints `/api/*`
- Servicios de negocio
- Validaciones Pydantic
- Autenticación JWT

### Frontend Web (Angular)
- Formularios de login/registro
- Catálogo y filtros
- Carrito y checkout
- Panel de admin

### Móvil (Flutter)
- Login y registro
- Catálogo
- Reservas
