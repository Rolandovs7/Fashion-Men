# Fundamentación Teórica: E-commerce

## 1. Visión General del E-commerce

El **comercio electrónico** (e-commerce) se refiere a la compra y venta de bienes o servicios a través de internet. Incluye tiendas en línea, transacciones digitales, cuentas de usuario y pasarelas de pago seguras.

### 1.1 Modelos de E-commerce

| Modelo | Descripción | Ejemplos |
|--------|-------------|----------|
| **B2C** (Business to Consumer) | Empresa vende a consumidor final | Amazon, Alibaba |
| **B2B** (Business to Business) | Empresa vende a otra empresa | Alibaba, Mercado Libre |
| **C2C** (Consumer to Consumer) | Consumidor vende a consumidor | eBay, Mercado Libre |
| **C2B** (Consumer to Business) | Consumidor vende a empresas | Freelancer |

## 2. Análisis como Usuario

### 2.1 Amazon

**Características clave:**
- Cuentas de usuario con historial de compras
- Búsqueda y filtros avanzados
- Recomendaciones personalizadas basadas en historial
- Suscripción Prime (envío gratis, servicios de streaming)
- Sistema de reseñas y calificaciones

**¿Qué aprender para MenStyle?**
- Recomendaciones personalizadas (aplicado en CU31)
- Filtros avanzados de catálogo (aplicado en CU14)
- Historial de compras (aplicado en CU33)

### 2.2 Alibaba

**Características clave:**
- Directorio de proveedores (B2B)
- Garantía comercial
- Compra al por mayor
- Alcance global con traducción

**¿Qué aprender para MenStyle?**
- Gestión de proveedores (aplicado en CU26)
- Asociación de productos a proveedores
- Control de stock con proveedores

### 2.3 Shopify

**Características clave:**
- Constructor de tiendas sin código
- Pagos integrados
- Analíticas de ventas
- Aplicaciones e integraciones
- Temas personalizables

**¿Qué aprender para MenStyle?**
- Dashboard administrativo (aplicado en CU29)
- Reportes de ventas (aplicado en CU30)
- Gestión integral de catálogo

## 3. Análisis como Desarrollador

### 3.1 Magento

**Características:**
- Plataforma open source
- Altamente personalizable
- Escalable para grandes inventarios
- Edición Community (gratis) y Enterprise (pago)
- Requiere experiencia técnica

**Ventajas para el desarrollo:**
- Arquitectura modular
- API REST completa
- Soporte multi-tienda

**Limitación para el proyecto:**
- ❌ **No se puede usar:** El PDF del examen prohíbe frameworks e-commerce preexistentes

### 3.2 PrestaShop

**Características:**

- Módulos y temas personalizables
- Ideal para PYMES
- Configuración rápida

**Limitación para el proyecto:**
- ❌ **No se puede usar:** Framework preexistente

**Características:**

- Convierte WordPress en tienda online
- Amplia gama de extensiones

- Fácil de usar

**Limitación para el proyecto:**
- ❌ **No se puede usar:** Framework preexistente
